## PemesananTiket

Aplikasi pemesanan tiket sederhana yang dibangun menggunakan Jetpack Compose, dibuat sebagai tugas praktikum.

## Fitur

* Harga tiket Rp40.000 per tiket
* Pengaturan jumlah tiket melalui tombol tambah/kurang (maksimum 10 tiket per pesanan)
* Indikator jumlah tiket yang terisi sesuai pilihan
* Perhitungan total pembayaran otomatis (jumlah tiket × harga tiket)
* Tombol reset untuk mengembalikan pemesanan ke kondisi awal

## Teknologi

* Kotlin
* Jetpack Compose

## Struktur Repository

* `app/` — source code project Android Studio
